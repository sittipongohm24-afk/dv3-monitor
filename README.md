# DV3 Monitor

ตรวจประกาศอัปเดตและกิจกรรม DV3 ทุกชั่วโมง นาทีที่ 7 ด้วย GitHub Actions แล้วส่งฉบับเต็มเข้า Discord เหมือนเดิม

## ภาพสรุปอัตโนมัติ

หลังส่งประกาศใหม่สำเร็จ ระบบเก็บเนื้อหาลง `summary_state.json` แล้วใช้ Gemini สรุปเป็นภาษาไทย พร้อมอ่านข้อความในภาพประกาศ (สูงสุด 24 ภาพ / ชุด) จากนั้น Playwright จัดภาพธีมกรมท่า–ม่วง–ทอง ฟอนต์ไทยจริง และภาพจากประกาศ ส่ง PNG หนึ่งรูปเข้าช่องสรุปอัปเดต

เพิ่ม Repository Secrets ที่ Settings → Secrets and variables → Actions:

- `GEMINI_API_KEY`: สร้างใน https://aistudio.google.com/apikey ใช้โครงการ Free Tier เท่านั้น ไม่ต้องเปิด billing สำหรับระบบนี้
- `DISCORD_SUMMARY_WEBHOOK_URL`: Discord ช่องสรุปอัปเดต → Edit Channel → Integrations → Webhooks → New Webhook → Copy Webhook URL

อย่าใส่ค่าคีย์/Webhook ลงไฟล์หรือข้อความสาธารณะ ตัวเชื่อม GitHub ในแชทตั้ง Secrets เหล่านี้ให้ไม่ได้

ใช้โมเดล `gemini-3.1-flash-lite` สำหรับสรุป ไม่เรียกบริการสร้างภาพ AI และไม่สลับไปโมเดลเสียเงิน อย่างไรก็ตามโค้ดไม่สามารถตรวจสถานะ billing ของโครงการได้ ผู้ดูแลต้องคงโครงการเป็น Free Tier เอง

## การส่งและลองใหม่

- รวมประกาศใหม่ที่ส่งฉบับเต็มสำเร็จในรอบเดียว สูงสุด 8 ประกาศต่อภาพ ที่เหลือรอรอบถัดไป
- หากยังไม่มี Secrets งานสรุปรออยู่ในคิว ฉบับเต็มยังส่งตามปกติ
- หาก AI เต็มโควตา/ตอบไม่ครบ/สร้างภาพไม่ผ่าน/Discord ส่งไม่สำเร็จ คงคิวไว้เพื่อลองรอบถัดไป โดยไม่ส่งฉบับเต็มซ้ำ
- เก็บ JSON สรุปสำเร็จไว้ใน `summary_output` เพื่อไม่เรียก AI ซ้ำเมื่อส่งภาพล้มเหลว PNG ดูได้ใน Actions artifact `dv3-summary` (14 วัน)
- ไม่ย้อนส่งประกาศเก่าที่อยู่ใน `seen.json` ก่อนติดตั้ง
- หาก Discord รับภาพแล้วแต่การตอบกลับหรือบันทึก state ล้มเหลว อาจส่งภาพซ้ำรอบถัดไปได้ (Webhook ไม่รับประกัน exactly-once)
- รูปเป็นแม่แบบอัตโนมัติ อัตราส่วน A4; ความสวยไม่เหมือนภาพ AI ที่ออกแบบเฉพาะครั้งทุกจุด และสรุป AI อาจผิดได้ จึงแนบลิงก์ต้นฉบับเสมอ
- อ่านได้เฉพาะประกาศใหม่ในสองบอร์ดที่ตั้งไว้ ไม่อ่านข้อความอื่นที่คนหรือบอทอื่นส่งใน Discord
- โควตา Gemini และ GitHub Actions ขึ้นกับแผนบัญชี ไม่รับประกันโควตาฟรีตลอดไป

## ทดสอบโดยไม่ส่งจริง

```sh
pip install playwright==1.58.0
playwright install chromium
python -m unittest discover -s tests -v
python tests/preview.py
```

ตัวอย่างใช้ข้อมูลสมมุติและไม่เรียก Gemini หรือ Discord. ก่อนเปิดใช้งานจริงควรตรวจภาพตัวอย่าง และเพิ่ม Secrets ทั้งสองค่า จากนั้น Actions → DV3 update monitor → Run workflow (ไม่ติ๊ก test) จะประมวลผลเมื่อมีประกาศใหม่หรือคิวค้าง
